DK Techin 우수 팀

사내 규정 / FAQ 기반 RAG 챗봇 · 2025.07 — 2025.08

문서 구조에서 사용자 피드백까지.
품질을 지속적으로 관리하는 흐름을 설계했습니다.

Problem
제목 중심 사내 문서에 맞는 검색 구조와, 오래된 피드백이 신규 문서를 밀어내는 문제를 고려해야 했습니다.
Decision
문서 구조에 맞는 chunking을 비교하고, 시간 기반 weight decay로 피드백의 영향을 조절하도록 설계했습니다.
Implementation
제목 기반 chunking, 사용자 평가와 문제 사유 저장, weight decay, Airflow 자동화를 연결했습니다.
Verification
약 50개 테스트 질문으로 여러 chunking 방식을 비교했습니다. 정답 문서가 Top-k에 포함되는지를 기준으로 평가했습니다.
Result
지속적인 품질 관리 구조를 설계했고, DK Techin 우수 팀에 선정됐습니다.
  1. 01

    Document Structure

    사내 규정과 FAQ 문서가 제목 중심으로 구성되어 있음을 분석했습니다.

  2. 02

    Chunking Experiment

    약 50개의 테스트 질문으로 정답 문서의 Top-k 포함 여부를 평가하고, 제목 기반 chunking을 적용했습니다.

  3. 03

    Feedback Structure

    사용자 평가와 문제 사유를 함께 저장해 품질 개선에 활용할 수 있도록 했습니다.

  4. 04

    Weight Decay

    오래된 feedback이 신규 문서를 밀어내는 문제를 줄이기 위해 시간 기반 weight decay를 설계했습니다.

  5. 05

    Airflow Automation

    Airflow로 품질 관리 흐름을 자동화했습니다.
